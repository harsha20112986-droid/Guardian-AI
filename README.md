# 🛡️ Guardian AI

Guardian AI is an AI-powered Digital Safety Assistant that helps users detect scams, phishing websites, malicious QR codes, and online threats.

## 🚀 Features

- Scam SMS Detection
- Phishing URL Detection
- QR Code Safety Checker
- AI Risk Explanation
- Dashboard
- History

## 🛠 Tech Stack

- React
- FastAPI
- Python
- Machine Learning
- SQLite/PostgreSQL
